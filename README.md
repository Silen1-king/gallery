# Silen1 的画室

一个纯静态的个人画作网站，核心想法是：

> **每一幅画里，都藏着一个洞。洞的那头，是下一幅画。**

- **首页**：往下滚，镜头会钻进当前这幅画的洞口，掉进下一幅画；一层一层往下掉，最后一幅画的洞又通回第一幅，整条路是一个圈。右边的小圆点是“深度计”，点一下可以直接跳到那一层。
- **作品画板**：所有的画像贴纸一样摊在一块大画板上，可以按住拖着逛；点“排整齐”切换成普通网格（手机上默认是网格）。
- **作品详情页**：大图、创作信息，以及可以播放和拖动进度的绘画过程回放。

全部是 HTML + CSS + 原生 JavaScript，**没有框架、不用编译、不连接任何外部网站**。任何能放静态文件的地方都能托管，费用为 0。

---

## 文件结构

```
index.html        首页（回放 + 作品画板 + 关于）
work.html         作品详情页，通过 work.html?id=作品id 打开
404.html          找不到页面时显示
css/style.css     所有样式，最上面的 :root 里可以改颜色
js/main.js        所有交互
data/works.js     作品列表（加画、改标题都在这里）
works/<id>/       每幅作品一个文件夹：大图、小图、缩时视频
assets/           网站图标、分享预览图 og.jpg
tools/add-work.py 自动处理并登记新作品的小工具
```

现在 `works/` 里的 6 幅画是**示例**，带“示例”标签。换成你自己的画之后删掉即可。

## 加一幅新画

### 方法一：用脚本（推荐）

需要 Python 3 和 Pillow（`pip install Pillow`），处理缩时视频还需要 ffmpeg。

1. 在 Procreate 里：**操作 → 分享 → PNG** 导出成品；**操作 → 视频 → 导出缩时视频**（选“30 秒”即可）。
2. 在网站文件夹里运行：

```bash
python3 tools/add-work.py \
  --id sleepy-cat \
  --title "睡着的猫" \
  --date 2026-11-01 \
  --image ~/Desktop/猫.png \
  --timelapse ~/Desktop/猫.mp4 \
  --hours 4 --brushes "6B 铅笔,水彩" \
  --notes "午后的光很好。" \
  --portal 0.62,0.35
```

脚本会自动压缩图片（WebP）、**清除图片和视频里的元数据**、把视频压到 720p 并控制在 24 秒内，然后写进 `data/works.js`。
`--portal` 是这幅画里**洞口的位置**（见下面“挑洞口”）。用同一个 `--id` 再运行一次就是更新。

### 方法二：手动

1. 在 `works/` 下新建文件夹，比如 `works/sleepy-cat/`。
2. 放入压缩好的大图（建议长边 2000 像素以内的 WebP 或 JPG）、一张宽 800 的小图，和可选的 `timelapse.mp4`。可以用 [Squoosh](https://squoosh.app) 在网页里压缩图片。
3. 打开 `data/works.js`，照着已有的格式加一项：

```json
{
  "id": "sleepy-cat",
  "title": "睡着的猫",
  "date": "2026-11-01",
  "image": "works/sleepy-cat/sleepy-cat.webp",
  "thumb": "works/sleepy-cat/sleepy-cat-thumb.webp",
  "width": 1600,
  "height": 2000,
  "timelapse": "works/sleepy-cat/timelapse.mp4",
  "app": "Procreate",
  "canvas": "2048 × 2560 px",
  "hours": 4,
  "brushes": ["6B 铅笔", "水彩"],
  "tags": ["猫"],
  "notes": "午后的光很好。",
  "portal": [0.62, 0.35]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 英文、数字和短横线，用在网址里 |
| `title` | 是 | 作品标题 |
| `image` | 是 | 大图路径 |
| `width` / `height` | 建议 | 大图的像素尺寸，用来提前占好位置、避免页面跳动 |
| `date` | 建议 | 完成日期，列表按它从新到旧排列 |
| `thumb` | 否 | 列表用的小图，不填就用大图 |
| `timelapse` | 否 | 缩时视频，有它才有回放 |
| `portal` | 建议 | 洞口位置 `[横, 纵]`，0 是左/上，1 是右/下。不填会随机挑一个 |
| 其它 | 否 | `app`、`canvas`、`hours`、`brushes`、`tags`、`notes` 会显示在详情页 |

注意 `works.js` 必须是合法的 JSON：用双引号，最后一项后面不要加逗号。

## 挑洞口

首页会按日期从新到旧，一幅接一幅地掉进去。洞口开在哪里，决定了“穿越”的感觉，挑一个画里本来就像入口的地方效果最好：一只眼睛、一扇窗、月亮、太阳、一盏灯、一个水坑。

示例里的洞口：鲸鱼的眼睛 → 月亮 → 树冠 → 橘子 → 太阳 → 海底的灯 → 又回到鲸鱼。

找坐标的办法：在 Procreate 或任何看图软件里看那个点的像素位置，除以画布宽高。比如 2048×2560 的画，洞口在 (1270, 900)，就是 `[0.62, 0.35]`。

画面在不同屏幕上会被裁掉一部分边缘，所以洞口尽量别太靠边，太靠边会被自动往里挪一点。

## 动态效果

- 首页的“坠落”只用了 CSS 缩放和圆形裁切，每次只渲染三幅画，图片在快掉到时才加载，手机上也流畅。
- 系统里开了“减少动态效果”的访客，不会看到坠落动画，直接看到作品画板。
- 详情页保留了绘画过程回放（Procreate 缩时视频），可以播放和拖动。

## 要改成你自己的地方

- `index.html` 里“关于”那一段的自我介绍和联系方式（目前是占位文字）。
- `assets/og.jpg`：分享到社交平台时显示的预览图，1200×630。
- 颜色：`css/style.css` 最上面的 `--sky`、`--sun`、`--peach`、`--mint`。
- 洞口大小、下一幅画在洞里的比例：`js/main.js` 里 `initDive` 开头的 `HOLE` 和 `K`。

## 本地预览

在网站文件夹里运行 `python3 -m http.server`，然后打开 <http://localhost:8000>。
直接双击 `index.html` 也能看，但部分浏览器会限制本地视频的拖动。

## 安全细节

- 每个页面都设置了内容安全策略（CSP）：只允许加载本站自己的脚本、样式、图片和视频，不加载任何第三方资源。
- 页面用 DOM API 插入作品数据，不拼接 HTML，标题里写了特殊字符也不会变成代码。
- 添加作品的脚本会去掉 EXIF、GPS 等元数据。
- 如果托管平台需要注入自己的脚本（比如统计代码）导致页面异常，把 `index.html` 和 `work.html` 里的 `Content-Security-Policy` 那一行删掉即可。
